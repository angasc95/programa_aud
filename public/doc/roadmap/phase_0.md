# **Informe de Análisis Arquitectónico Profundo y Roadmap de Desarrollo por Fases del Sistema programa\_aud**

El diseño y la implementación de una plataforma de software orientada a la gestión de programas de auditoría y certificación bajo normas internacionales de sistemas de gestión —específicamente **ISO/IEC 17021-1:2015** (requisitos para organismos de evaluación de la conformidad) e **ISO 19011:2018** (directrices para la auditoría de sistemas de gestión)— exigen un rigor técnico elevado en la persistencia de datos, la trazabilidad de operaciones y el control de acceso granular1. El proyecto programa\_aud aborda estas exigencias mediante un esquema relacional robusto respaldado por la infraestructura de PostgreSQL en Supabase y una interfaz cliente reactiva desarrollada bajo el patrón de aplicación de página única (Single-Page Application o SPA)1.  
Para garantizar que el sistema mantenga una absoluta estabilidad estructural y no incurra en deuda técnica a medida que se incorporan módulos operativos complejos, el plan de desarrollo adopta una estrategia metodológica estrictamente secuencial, organizando el avance en cinco fases bien delimitadas1. Esta aproximación progresiva asegura que cada capa conceptual, desde la seguridad infraestructural hasta la interfaz de navegación profunda, sea validada técnicamente antes de construir las abstracciones del nivel superior1.
